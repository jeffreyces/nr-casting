# Fallback: catalysts whose schools must be stated, for builds where the flag offsets no longer
# validate.
#
# The schools are read from two flag bits in the weapon's own EquipParamWeapon row - 0x80 in
# bits_105 for sorceries, 0x02 in bits_106 for incantations - which every vanilla staff (0x87/0x10),
# every vanilla seal (0x07/0x12) and both dual catalysts (0x87/0x12: the Staff of the Great Beyond
# and a class port's staff) agree on. The paramdef does not name those bytes, so they are read by
# offset and checked against a known staff and seal before they are trusted; if a patch moves them,
# this table is what keeps the dual catalysts working.
#
# Format: weapon_param_id = sorcery | incantation | both
# Base ids only: the upgrade level is the low two digits and is stripped before the lookup.
#
# Anything not listed keeps the band rule, and a catalyst this table does not know AND the name
# table does not name is a content mod's, which is offered both schools: guessing "sorcery only"
# hides spells the player can really cast, while offering one it cannot costs a failed cast.

33510000 = both    # Staff of the Great Beyond (Shadow of the Erdtree)
